# 合规控制矩阵
**源文件**: 中华人民共和国数据安全法

| 涉及领域 | 控制目标 | 法律要求（条款摘要） | 控制点（审计标准） | 类型 |
| :--- | :--- | :--- | :--- | :--- |
| 网络安全管理制度 | 制定并实施数据处理活动的安全管理制度 | 【第一条】要求制定本法以规范数据处理活动，保障数据安全 | 制定并发布正式的数据安全管理制度体系，明确数据处理活动的安全要求，并保留制度发布审批记录及员工培训签到表 | 强制 |
| 网络安全管理制度 | 提高数据安全保障能力 | 【第四条】要求建立健全数据安全治理体系，提高数据安全保障能力 | 建立健全数据安全治理体系，包括数据分类分级、风险评估、安全审计等机制，并定期进行安全评估和审计 | 强制 |
| 网络安全管理机构 | 明确数据安全监管职责 | 【第六条】规定各地区、各部门的数据安全监管职责 | 制定并发布数据安全监管职责分工文件，明确各地区、各部门的数据安全监管职责，并进行定期培训和考核 | 强制 |
| 数据保护 | 保障数据依法有序自由流动 | 【第七条】规定国家保障数据依法有序自由流动 | 制定数据流动管理制度，确保数据在合法合规的前提下自由流动，并建立数据流动审批流程 | 强制 |
| 第三方服务商管理 | 加强数据安全保护 | 【第十条】规定行业组织制定数据安全行为规范和团体标准 | 制定第三方服务商数据安全行为规范，确保服务商遵守数据安全保护要求，并进行定期审核和评估 | 推荐 |
| 网络安全管理制度 | 提高数据安全保护意识 | 【第九条】规定国家支持数据安全知识宣传普及 | 制定数据安全知识宣传普及计划，定期组织数据安全培训和宣传活动，并保留培训和活动记录 | 推荐 |
| 网络安全管理制度 | 确保数据开发利用和产业发展符合国家数据安全要求 | 【第13条】要求网络运营者在数据开发利用和产业发展中保障数据安全。 | 制定并发布数据开发利用和数据安全管理制度，明确数据安全保护措施，并确保制度得到有效执行。 | 强制 |
| 数据保护 | 提升公共服务智能化水平，确保老年人、残疾人的需求得到满足 | 【第15条】要求智能化公共服务充分考虑老年人、残疾人的需求。 | 制定智能化公共服务方案，确保方案符合老年人、残疾人的需求，并进行定期评估和改进。 | 强制 |
| 数据保护 | 支持数据开发利用和数据安全技术研究，促进技术推广和商业创新 | 【第16条】鼓励数据开发利用和数据安全技术研究和商业创新。 | 设立专门的研发团队，开展数据开发利用和数据安全技术研究，并推广研究成果。 | 推荐 |
| 数据保护 | 推动数据开发利用技术和数据安全标准体系建设 | 【第17条】国家推进数据开发利用技术和数据安全标准体系建设。 | 参与或支持数据开发利用技术和数据安全相关标准的制定和修订工作。 | 推荐 |
| 数据保护 | 支持数据安全检测评估、认证服务的发展 | 【第18条】国家促进数据安全检测评估、认证服务的发展。 | 支持数据安全检测评估、认证等专业机构依法开展服务活动，并参与相关协作。 | 推荐 |
| 数据保护 | 建立健全数据交易管理制度，规范数据交易行为 | 【第19条】国家建立健全数据交易管理制度，规范数据交易行为。 | 制定数据交易管理制度，规范数据交易行为，并确保制度得到有效执行。 | 强制 |
| 数据保护 | 支持数据开发利用技术和数据安全教育和培训 | 【第20条】国家支持教育、科研机构和企业等开展数据开发利用技术和数据安全教育和培训。 | 支持教育、科研机构和企业等开展数据开发利用技术和数据安全教育和培训，并促进人才交流。 | 推荐 |
| 数据保护 | 确保数据分类分级保护制度的实施 | 【第二十一条】要求各地区、各部门确定本地区、本部门以及相关行业、领域的重要数据具体目录，对列入目录的数据进行重点保护。 | 制定并发布数据分类分级保护制度，明确重要数据目录，并对重要数据采取加强保护措施，保留制度发布审批记录及员工培训签到表。 | 强制 |
| 数据保护 | 建立数据安全风险评估机制 | 【第二十二条】要求建立数据安全风险评估机制。 | 建立数据安全风险评估机制，定期进行风险评估，并形成评估报告，保留评估报告及风险信息获取、分析、研判、预警记录。 | 强制 |
| 数据保护 | 建立数据安全应急处置机制 | 【第二十三条】要求建立数据安全应急处置机制。 | 制定数据安全应急预案，定期进行应急演练，并在发生数据安全事件时启动应急预案，采取应急措施，消除安全隐患，并及时发布警示信息。 | 强制 |
| 数据保护 | 实施数据安全审查制度 | 【第二十四条】要求建立数据安全审查制度。 | 制定数据安全审查制度，对影响或可能影响国家安全的数据处理活动进行审查，并保留审查记录。 | 强制 |
| 数据保护 | 实施数据出口管制 | 【第二十五条】要求对属于管制物项的数据依法实施出口管制。 | 制定数据出口管制制度，明确管制物项数据的范围，并对出口进行审查和控制，保留审查记录。 | 强制 |
| 数据保护 | 对采取歧视性措施的国家或地区采取对等措施 | 【第二十六条】要求对采取歧视性措施的国家或地区采取对等措施。 | 制定对采取歧视性措施的国家或地区的应对措施，并在必要时采取对等措施，保留相关记录。 | 强制 |
| 数据保护 | 确保数据处理活动符合法律、法规要求，保障数据安全 | 【第二十七条】要求数据处理者建立健全全流程数据安全管理制度，采取技术措施和其他必要措施保障数据安全，加强风险监测和补救措施。 | 制定并发布数据安全管理制度和操作规程，明确数据处理流程中的安全措施，定期进行风险评估，并留存评估报告。 | 强制 |
| 数据保护 | 确保数据处理活动符合社会公德和伦理 | 【第二十八条】要求数据处理活动符合社会公德和伦理。 | 制定并发布数据处理活动的伦理规范，确保数据处理符合社会公德和伦理。 | 推荐 |
| 数据保护 | 加强数据风险监测，及时采取补救措施 | 【第二十九条】要求数据处理者加强风险监测，发现风险立即采取补救措施，发生数据安全事件时立即采取处置措施并向主管部门报告。 | 建立风险监测机制，定期检查数据安全风险，留存风险监测记录和补救措施记录。 | 强制 |
| 数据保护 | 定期开展风险评估并报告 | 【第三十条】要求重要数据处理者定期开展风险评估并向主管部门报告。 | 制定风险评估计划，定期进行风险评估，留存风险评估报告。 | 强制 |
| 数据保护 | 确保数据出境安全 | 【第三十一条】规定数据出境安全管理规定。 | 制定数据出境安全管理制度，确保数据出境符合相关法规要求。 | 强制 |
| 数据保护 | 确保数据收集合法、正当 | 【第三十二条】规定数据收集应当合法、正当，不得非法获取数据。 | 制定数据收集政策，确保数据收集符合法律、法规要求。 | 强制 |
| 数据保护 | 确保数据交易合规 | 【第三十三条】规定数据交易中介服务应当审核数据来源和交易双方身份。 | 制定数据交易审核制度，确保数据交易符合法规要求。 | 强制 |
| 数据保护 | 确保数据服务合规 | 【第三十四条】规定提供数据处理服务应当取得行政许可。 | 确保数据服务提供者取得相关行政许可。 | 强制 |
| 数据保护 | 确保数据调取合规 | 【第三十五条】规定数据调取应当按照国家规定进行。 | 制定数据调取政策，确保数据调取符合法规要求。 | 强制 |
| 数据保护 | 确保数据跨境提供合规 | 【第三十六条】规定数据跨境提供应当经过主管机关批准。 | 制定数据跨境提供管理制度，确保数据跨境提供符合法规要求。 | 强制 |
| 数据保护 | 确保政务数据的安全性和保密性 | 【第三十八条】要求国家机关在履行法定职责时，对个人隐私、个人信息、商业秘密等数据依法保密，不得泄露或非法提供。 | 制定并实施数据保密制度，明确数据保密范围、保密措施及违规处罚机制；对涉密数据进行分类管理，确保数据在存储、传输、使用过程中的安全；定期进行数据保密培训，确保员工了解保密义务。 | 强制 |
| 数据保护 | 确保政务数据的安全性和完整性 | 【第三十九条】要求国家机关建立健全数据安全管理制度，落实数据安全保护责任。 | 制定并发布正式的数据安全管理制度，明确数据安全保护责任；定期进行数据安全风险评估，确保数据安全措施的有效性；建立数据安全事件应急响应机制，确保数据安全事件的及时处理。 | 强制 |
| 第三方服务商管理 | 确保第三方服务商的数据安全保护义务得到履行 | 【第四十条】要求国家机关在委托第三方建设、维护电子政务系统时，需经过批准程序，并监督第三方履行数据安全保护义务。 | 制定第三方服务商数据安全保护协议，明确数据安全保护义务；建立第三方服务商数据安全审查机制，确保服务商符合数据安全保护要求；定期进行第三方服务商数据安全审计，确保服务商履行数据安全保护义务。 | 强制 |
| 数据保护 | 确保政务数据的公开符合规定 | 【第四十一条】要求国家机关遵循公正、公平、便民的原则，按照规定及时、准确地公开政务数据。 | 制定政务数据公开管理制度，明确数据公开的原则、范围、程序；建立政务数据公开审批流程，确保数据公开符合规定；定期进行政务数据公开审计，确保数据公开的合规性。 | 强制 |

| 数据保护 | 确保数据处理活动符合法律要求，保障数据安全 | 【第四十五条】规定数据处理组织和个人必须履行数据安全保护义务，否则将面临罚款、业务暂停等处罚 | 制定并执行数据安全保护政策，确保所有数据处理活动符合法律要求，并保留相关记录 | 强制 |
