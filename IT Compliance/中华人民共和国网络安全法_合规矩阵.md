# 合规控制矩阵
**源文件**: 中华人民共和国网络安全法

| 涉及领域 | 控制目标 | 法律要求（条款摘要） | 控制点（审计标准） | 类型 |
| :--- | :--- | :--- | :--- | :--- |
| 网络安全管理制度 | 制定内部安全管理制度和操作规程，保障网络安全 | 【第21条第1款】要求网络运营者制定内部安全管理制度和操作规程。 | 建立并发布正式的网络安全管理制度体系，明确各级人员安全职责，并保留制度发布审批记录及员工培训签到表。 | 强制 |
| 网络安全管理制度 | 确保网络运营者建立有效的内部安全管理制度 | 【第21条第1款】要求网络运营者制定内部安全管理制度和操作规程。 | 建立并发布正式的网络安全管理制度体系，明确各级人员安全职责，并保留制度发布审批记录及员工培训签到表。 | 强制 |
| 网络安全管理机构 | 确保网络运营者设立专门的安全管理机构 | 【第25条】网络运营者应当制定网络安全事件应急预案，并定期组织演练。 | 成立专门的网络安全管理机构，明确其职责范围，并确保其具备足够的资源和权限来执行网络安全管理任务。 | 强制 |

| 网络安全管理制度 | 明确网络安全保护义务和责任 | 【第十条】要求网络运营者必须遵守法律、行政法规，履行网络安全保护义务。 | 制定并发布网络安全管理制度和操作规程，明确各级人员的安全职责，并保留制度发布审批记录及员工培训签到表。 | 强制 |
| 网络安全管理制度 | 确保网络稳定运行和数据安全 | 【第十一款】要求网络运营者采取技术措施和其他必要措施保障网络安全、稳定运行。 | 建立并实施网络安全技术措施和管理措施，确保网络稳定运行和数据的完整性、保密性和可用性，并保留相关技术配置和过程记录。 | 强制 |
| 网络安全管理制度 | 加强行业自律和规范 | 【第十二款】要求网络相关行业组织加强行业自律，制定网络安全行为规范。 | 行业组织应制定并发布网络安全行为规范，指导会员加强网络安全保护，并保留规范发布和培训记录。 | 推荐 |
| 网络安全管理制度 | 保护公民合法网络使用权利 | 【第十三款】要求国家保护公民合法使用网络的权利，促进网络服务健康发展。 | 制定并实施保护公民合法网络使用权利的措施，确保网络服务的安全便利，并保留相关服务记录。 | 强制 |
| 网络安全管理制度 | 保护未成年人网络环境 | 【第十四款】要求国家支持有利于未成年人健康成长的网络产品和服务。 | 制定并实施保护未成年人网络环境的措施，确保未成年人使用网络的安全健康，并保留相关措施实施记录。 | 强制 |
| 网络安全管理制度 | 建立举报机制 | 【第十五款】要求任何个人和组织有权举报危害网络安全的行为。 | 建立并公布举报机制，确保举报信息保密，并及时依法处理举报，保留举报处理记录。 | 强制 |
| 网络安全管理制度 | 提升网络安全技术水平和保护知识产权 | 【第16条】要求制定和适时修订网络安全管理及网络产品、服务和运行安全的国家标准、行业标准。 | 制定并发布网络安全国家标准和行业标准，确保企业参与标准制定过程，并保留参与记录。 | 强制 |
| 网络安全管理制度 | 支持网络安全技术创新和应用 | 【第17条】要求政府扶持网络安全技术产业和项目，支持技术研究开发和应用。 | 制定并实施网络安全技术创新项目支持政策，确保企业参与技术创新项目，并保留项目参与记录。 | 强制 |
| 网络安全管理制度 | 推动网络安全社会化服务体系 | 【第18条】鼓励企业、机构开展网络安全认证、检测和风险评估等服务。 | 建立网络安全服务供应商名单，确保企业参与网络安全服务，并保留服务合同和评估报告。 | 推荐 |
| 数据保护 | 提升数据安全保护和利用技术 | 【第19条】鼓励开发网络数据安全保护和利用技术，促进公共数据资源开放。 | 制定数据安全保护和利用技术开发计划，确保企业参与技术开发，并保留技术开发记录。 | 推荐 |
| 网络安全管理制度 | 提升网络安全保护水平 | 【第20条】支持人工智能基础理论研究和算法研发，提升网络安全保护水平。 | 制定并实施人工智能技术在网络安全中的应用计划，确保企业参与技术研发，并保留技术研发记录。 | 强制 |
| 网络安全管理制度 | 加强网络安全宣传教育 | 【第21条】各级政府及其部门应当组织开展网络安全宣传教育。 | 制定并实施网络安全宣传教育计划，确保企业参与宣传教育，并保留宣传教育记录。 | 强制 |
| 网络安全管理制度 | 培养网络安全人才 | 【第22条】支持企业和教育培训机构开展网络安全教育与培训。 | 制定并实施网络安全人才培养计划，确保企业参与人才培养，并保留培训记录。 | 强制 |
| 网络安全等级保护 | 确保网络免受干扰、破坏或未经授权的访问，防止数据泄露或篡改 | 【第二十三条】要求网络运营者履行安全保护义务，保障网络安全 | 制定内部安全管理制度和操作规程，确定网络安全负责人，落实安全保护责任；采取防范计算机病毒和网络攻击的技术措施；采取监测、记录网络运行状态的技术措施，并留存相关网络日志不少于六个月；采取数据分类、重要数据备份和加密措施。 | 强制 |
| 网络安全管理制度 | 制定网络安全事件应急预案，及时处置安全风险 | 【第二十七条】要求网络运营者制定网络安全事件应急预案，及时处置安全风险 | 制定网络安全事件应急预案，定期进行演练，并在发生网络安全事件时立即启动应急预案，采取相应补救措施，并按规定向有关主管部门报告。 | 强制 |
| 第三方服务商管理 | 网络产品和服务提供者不得设置恶意程序，发现安全缺陷时应立即采取补救措施 | 【第二十四条】要求网络产品和服务提供者不得设置恶意程序，发现安全缺陷时应立即采取补救措施 | 网络产品和服务提供者应确保其产品和服务符合相关国家标准的强制性要求，不得设置恶意程序；发现安全缺陷时应立即采取补救措施，并按规定告知用户和报告主管部门。 | 强制 |
| 数据保护 | 网络运营者应确保收集和产生的个人信息和重要数据在境内存储 | 【第三十九条】要求关键信息基础设施的运营者在境内存储个人信息和重要数据 | 网络运营者应确保在境内存储个人信息和重要数据；如需向境外提供，应按照国家网信部门会同国务院有关部门制定的办法进行安全评估。 | 强制 |
