# Group Cloud Security Policy

## Identity and Access Management

- All production cloud accounts must use multi-factor authentication for privileged access.
- Shared administrator accounts must not be used.
- Access rights must be reviewed at least quarterly.

## Logging and Monitoring

- Security-relevant events must be centrally logged and retained for at least 180 days.
- Alerting must be enabled for unauthorized access attempts and critical configuration changes.

## Data Protection

- Sensitive data stored in cloud services must be encrypted at rest.
- Sensitive data transmitted between services must be encrypted in transit.
