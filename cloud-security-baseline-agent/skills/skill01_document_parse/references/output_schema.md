# Output Schema

Each parse artifact should contain:

- `document_role`
- `document_name`
- `source_files`
- `source_quality`
- `requirements`
- `thematic_signals`
- `parsing_notes`
- `parser_strategy`

Each requirement should contain:

- `requirement_id`
- `source_requirement_id`
- `section`
- `statement`
- `category`
- `priority`
- `service`
- `source_excerpt`
- `source_file`
